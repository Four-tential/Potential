후기 정책
후기 작성 조건
후기는 다음 세 가지 조건을 모두 만족해야 작성할 수 있습니다.
해당 코스 주문이 결제 확정 상태여야 합니다. 결제 대기, 결제 완료, 취소, 만료 상태에서는 작성할 수 없습니다.
코스가 종료된 상태여야 합니다. 코스 종료 일시가 지나기 전까지는 후기를 작성할 수 없습니다.
출석 상태가 출석 완료여야 합니다. 결석 상태인 회원은 후기를 작성할 수 없습니다.
키워드: 후기 작성 조건, 결제 확정, 코스 종료, 출석 완료, 후기 자격
후기 작성 기간
후기는 코스 종료 후 7일 이내에만 작성할 수 있습니다. 7일이 지나면 더 이상 작성할 수 없습니다. 수정도 동일하게 코스 종료 후 7일 이내로 제한됩니다.
키워드: 후기 작성 기간, 7일 제한, 후기 마감, 후기 수정 기간
후기 중복 작성
동일한 코스에 대해 한 회원은 한 건의 후기만 작성할 수 있습니다. 이미 후기를 작성한 코스에 다시 후기를 등록하려고 하면 중복 오류가 안내되며 작성이 거절됩니다.
키워드: 1인 1후기, 중복 작성, 중복 후기, 후기 한 번만
별점과 내용
별점은 1점에서 5점 사이의 정수만 허용됩니다. 범위를 벗어난 별점이 입력되면 잘못된 요청 오류가 반환됩니다.
후기 내용은 필수 입력 항목이며 최대 2,000자까지 작성할 수 있습니다. 이미지 첨부는 선택 사항이며 S3 업로드 후 전달된 URL 형태로 등록됩니다.
키워드: 별점, 1~5점, 후기 내용, 글자 수 제한, 이미지 첨부
후기 수정
후기 수정은 본인만 가능합니다. 다른 회원이나 강사는 수정할 수 없으며 관리자도 후기 내용 자체는 수정하지 않습니다. 수정 가능한 기간은 코스 종료 후 7일까지로 작성 기간과 동일합니다.
이미지 URL을 함께 전달하면 기존 이미지 목록 전체가 새로운 목록으로 덮어쓰입니다. 일부만 갱신되는 방식이 아닙니다.
키워드: 후기 수정, 본인 수정, 이미지 덮어쓰기, 후기 변경
후기 삭제
후기 삭제는 작성 본인 또는 관리자만 가능합니다. 후기를 삭제하면 연결된 후기 이미지도 함께 삭제됩니다.
키워드: 후기 삭제, 본인 삭제, 관리자 삭제, 이미지 함께 삭제
후기 조회
후기 목록은 비로그인 사용자도 조회할 수 있습니다.
내가 좋아요를 눌렀는지를 나타내는 정보는 로그인한 사용자에게만 제공됩니다. 비로그인 상태에서는 해당 정보가 비어 있는 값으로 반환됩니다.
키워드: 후기 조회, 비로그인 조회, 좋아요 표시, myLiked
