주문 정책
주문 가능 회원
주문은 일반 수강생만 신청할 수 있습니다. 강사도 다른 강사의 코스를 수강하기 위해 주문할 때는 일반 수강생과 동일하게 처리됩니다.
키워드: 주문 자격, 수강생 주문, 일반 회원 주문
주문 생성 조건
주문은 코스에 잔여석이 있을 때만 생성할 수 있습니다. 주문하기 버튼을 누른 시점에 다른 사람이 결제 중이라 잔여석이 없다면 주문을 생성할 수 없으며, 대신 대기열에 등록됩니다. 동일한 회원이 같은 시간대에 진행되는 다른 코스를 이미 예약한 경우에도 주문을 생성할 수 없습니다.
키워드: 주문 생성, 잔여석, 결제 중 자리 없음, 동일 시간대 중복 예약
주문 상태
주문은 결제 대기, 결제 완료, 결제 확정, 주문 취소, 결제 만료 다섯 가지 상태를 가집니다.
결제 대기 상태는 주문하기 버튼을 눌러 자리를 점유한 직후의 상태로, 10분 동안만 유효합니다.
결제 완료 상태는 결제가 정상적으로 완료되어 수강 권한을 완전히 획득한 상태입니다.
결제 확정 상태는 환불 가능 기간이 지나 결제가 최종 확정된 상태입니다. 환불 가능 기간은 코스 시작 7일 전까지이므로, 그 시점이 지나면 결제 완료 상태가 자동으로 결제 확정 상태로 전환됩니다.
주문 취소 상태는 회원이 결제 전에 직접 취소했거나, 10분이 초과되어 시스템이 취소했거나, 강사 코스 취소 등으로 환불이 진행된 상태입니다.
결제 만료 상태는 10분 결제 제한 시간이 지나 결제가 더 이상 불가능해진 상태입니다.
키워드: 주문 상태, 결제 대기, 결제 완료, 결제 확정, 주문 취소, 결제 만료
주문 유효 시간
결제 대기 상태의 주문은 생성 시점부터 10분 동안만 유효합니다. 10분 안에 결제 완료 웹훅이 도착하지 않으면 주문은 자동으로 결제 만료 상태로 전환됩니다. 결제가 정상적으로 완료되면 결제 완료 상태가 됩니다.
키워드: 결제 제한 시간, 10분 제한, 결제 만료, 자동 만료
환불과 결제 확정
환불 가능 기간이 지나면 결제 완료 상태는 결제 확정 상태로 자동 전환됩니다. 결제 확정 이후에는 수강생이 직접 환불할 수 없습니다.
키워드: 결제 확정, 환불 마감, 환불 기간 종료
주문 취소
회원은 코스 시작 7일 전까지 직접 주문을 취소할 수 있으며, 취소 시 주문은 취소 상태가 됩니다. 강사가 코스를 취소한 경우에는 해당 코스의 결제 완료 및 결제 확정 상태 주문이 모두 자동으로 취소 상태로 전환됩니다.
주문이 취소되면 점유하고 있던 자리는 즉시 해제되어 대기열의 다음 사람에게 넘어갑니다.
키워드: 주문 취소, 자발적 취소, 강사 취소, 자리 양도, 대기열 이관
대기열
정원이 모두 찬 코스는 대기열에 등록할 수 있으며, 코스당 최대 대기 순번은 200번까지입니다.
대기 중인 회원에게는 현재 대기 순번, 앞 순번 회원들의 평균 결제 시간을 기반으로 한 예상 대기 시간, 현재 결제 대기 중인 인원 수가 함께 표시됩니다. 대기열을 취소하면 다음 사람의 순번이 앞당겨집니다. 앞 사람이 결제에 실패하거나 대기를 취소하면 자리는 다음 대기자에게 자동으로 넘어갑니다.
키워드: 대기열, 대기 순번, 예상 대기 시간, 대기 취소, 대기 200번
