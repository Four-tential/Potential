# 공통 정책
## 삭제 정책
서비스 전반의 삭제 정책은 고객의 이용 데이터를 일부 보존합니다.
키워드: 삭제, 소프트 삭제, 데이터 보존, 이력 데이터, 삭제 불가
## 권한 구분
서비스 이용자는 일반 수강생, 강사, 관리자 세 역할 중 하나의 역할만 가집니다. 한 회원이 동시에 여러 역할을 갖지 않으며, 강사로 전환되면 일반 수강생 역할은 유지되지 않습니다. 일반 수강생도 강사도 결제, 출석, 후기 작성 같은 기본적인 서비스 이용은 동일하게 가능합니다.
키워드: 단일 역할, 회원 역할, 권한, 수강생, 강사, 관리자
## 응답 메시지 형식
서비스에서 안내되는 메시지와 알림은 짧고 명확한 한국어 단답형으로 제공됩니다. 오류 안내, 성공 안내, 검증 메시지 모두 길게 풀어쓰지 않고 핵심만 전달합니다.
키워드: 메시지, 알림, 단답형, 한국어 안내
