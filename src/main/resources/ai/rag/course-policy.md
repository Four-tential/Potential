# 코스 정책
## 코스 개설 권한
코스는 강사 또는 관리자만 개설할 수 있으며 일반 수강생은 개설할 수 없습니다. 강사가 개설을 신청하면 검토 대기 상태로 시작되고, 관리자가 직접 개설하면 별도 승인 없이 바로 공개 상태가 될 수 있습니다.
키워드: 코스 개설, 코스 등록, 강사 개설, 관리자 개설, 개설 권한
## 코스 상태
코스는 검토 대기, 공개, 종료, 취소 네 가지 상태를 가집니다.
검토 대기 상태는 강사가 개설을 신청한 직후의 상태입니다. 일반 수강생과 다른 강사에게는 노출되지 않으며, 관리자의 승인을 기다리는 초기 상태입니다. 이 상태에서는 코스의 모든 정보를 수정할 수 있습니다. 관리자는 모든 검토 대기 코스를 수정할 수 있고, 강사는 본인이 개설한 코스만 수정할 수 있습니다.
공개 상태는 관리자의 승인 또는 관리자의 직접 개설을 통해 공개된 상태입니다. 수강생이 코스를 검색하고 결제할 수 있습니다. 공개 상태에서는 가격, 일정, 장소, 정원 정보는 수정할 수 없으며 그 외 정보는 권한에 따라 수정 가능합니다.
종료 상태는 수업이 끝난 상태입니다. 더 이상 신규 주문을 받을 수 없고, 코스가 종료되면 후기 작성 기간이 시작됩니다.
취소 상태는 강사 또는 관리자에 의해 코스가 취소된 상태입니다. 신규 예약과 결제가 불가능하며, 이미 결제한 회원에게는 자동으로 환불이 진행됩니다.
키워드: 코스 상태, 검토 대기, 공개 코스, 종료된 코스, 취소된 코스
## 코스 상태 전이 규칙
검토 대기 상태에서 공개 상태로의 전환은 관리자의 승인을 통해서만 가능합니다.
공개 상태에서 종료 상태로의 전환은 수업이 끝나면 이루어집니다.
공개 상태에서 취소 상태로의 전환은 강사 또는 관리자가 진행할 수 있습니다.
검토 대기 상태에서 취소 상태로의 전환도 강사 또는 관리자가 가능합니다.
종료 상태나 취소 상태에서 다시 공개 상태로 되돌아가는 것은 허용되지 않습니다.
키워드: 코스 상태 변경, 코스 승인, 코스 취소, 코스 재공개 불가
## 코스 정원과 자동 종료
코스 정원은 1명 이상이어야 합니다. 코스 시작 일시까지 정원이 0명인 경우 코스는 자동으로 종료 상태로 전환됩니다.
키워드: 코스 정원, 최소 인원, 자동 종료, 정원 미달
## 주문 마감 시간
코스의 주문 마감 시간은 주문 가능 시작 시각 이후여야 하고, 코스 시작 일시 두 시간 전까지로만 설정할 수 있습니다. 코스 시작 두 시간 이내에는 주문을 받지 않습니다.
키워드: 주문 마감, 주문 마감 시간, 주문 가능 시간, 마감 두 시간 전
## 대기열 등록
주문 시 정원이 모두 찬 경우 회원은 대기열에 등록할 수 있습니다. 대기열 운영에 대한 자세한 규칙은 주문 정책을 참고합니다.
키워드: 대기열, 정원 마감, 대기 등록
## 카테고리
하나의 코스는 하나의 카테고리에만 속합니다. 여러 카테고리를 동시에 가질 수 없습니다.
키워드: 카테고리, 분류, 단일 카테고리
## 코스 정보 수정 권한
검토 대기 상태에서는 코스의 모든 정보를 수정할 수 있습니다. 공개 상태에서는 가격, 일정, 장소, 정원에 대한 정보를 수정할 수 없으며 그 외 정보는 수정할 수 있습니다. 관리자는 모든 코스에 대해 수정 권한을 가지고, 강사는 본인이 개설한 코스에 대해서만 수정할 수 있습니다. 종료된 코스와 취소된 코스는 수정할 수 없습니다.
키워드: 코스 수정, 가격 수정 불가, 일정 변경 불가, 정원 변경 불가, 코스 정보 변경
