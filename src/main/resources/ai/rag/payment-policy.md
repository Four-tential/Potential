# 결제 정책
## 결제 상태
결제는 결제 대기, 결제 완료, 부분 환불, 전액 환불, 결제 실패 다섯 가지 상태를 가집니다.
결제 대기 상태는 결제 요청이 생성되어 PG사 처리를 기다리는 상태입니다.
결제 완료 상태는 PG사 웹훅을 통해 결제가 정상적으로 완료된 상태입니다.
부분 환불 상태는 다수 수강권 중 일부만 환불이 완료된 상태이며, 추가 환불을 통해 전액 환불 상태로 전환될 수 있습니다.
전액 환불 상태는 결제한 수강권 전체에 대한 환불이 완료된 상태입니다. 이 상태에서는 더 이상 추가 환불이 불가능합니다.
결제 실패 상태는 PG사 결제 처리가 실패한 최종 상태입니다.
키워드: 결제 상태, 결제 완료, 결제 실패, 부분 환불, 전액 환불
## 결제 생성 조건
결제는 결제 대기 상태의 주문에 대해서만 생성할 수 있습니다. 동일한 주문에 대해 결제는 한 건만 존재할 수 있으며, 중복 결제는 허용되지 않습니다.
결제 수단은 카드만 허용합니다. 다른 결제 수단으로 들어온 요청은 거절됩니다.
PG사에서 반환한 실제 결제 금액과 주문 금액이 일치하지 않으면 즉시 결제를 취소하고 요청을 거절합니다.
키워드: 결제 생성, 카드 결제, 결제 수단 제한, 금액 불일치, 중복 결제 불가
## 결제 완료 처리
PG사 웹훅에서 결제 완료 이벤트를 수신하면 결제 완료로 처리합니다. 이때 결제 정보가 결제 완료 상태로 생성되고, 해당 주문은 결제 완료 상태로 변경되며, 코스의 확정 인원 수가 결제한 수강권 수량만큼 증가합니다. 이 모든 처리는 하나의 트랜잭션으로 묶여 부분적으로만 반영되지 않도록 보장됩니다.
키워드: 결제 완료 처리, 결제 웹훅, 확정 인원 증가, 트랜잭션
## 결제 실패 처리
PG사 웹훅에서 결제 실패 이벤트를 수신하면 결제 실패로 처리합니다. 결제 정보는 결제 실패 상태로 생성되고, 해당 주문은 취소 상태로 변경됩니다.
주문이 취소되어 자리가 비면 대기열의 가장 앞 순번 회원에게 자동으로 결제 기회가 넘어갑니다.
결제 실패로 인한 주문 취소는 결제 확정 상태였던 적이 없으므로 코스의 확정 인원 수는 변경되지 않습니다.
키워드: 결제 실패, 결제 실패 웹훅, 자동 대기열 승계, 확정 인원 유지
